Uma **Escritura** é um ato lavrado em cartório de notas e enviado à **CESDI**, a Central de Escrituras de Separações, Divórcios e Inventários da CENSEC. A consulta é feita **ao vivo** na CENSEC por CPF ou CNPJ e devolve cada ato em que o documento aparece, com todas as partes envolvidas.

<Info>
  A CESDI só reúne escrituras **lavradas em cartório**. Separações, divórcios e inventários feitos na Justiça ficam nos tribunais. Para esses, use a [busca de processos](/entidades/processo) com a categoria [Família e Sucessões](/categorias/familia-sucessoes).
</Info>

### Campos da resposta

| Campo | Descrição |
| --- | --- |
| `total` | Número de escrituras distintas. `0` quando não há escritura, e nesse caso os tokens são estornados |
| `possivelmente_truncado` | `true` quando a CENSEC atingiu o limite de 300 registros por busca |
| `cobertura` | Lembrete de que atos judiciais não estão na CESDI |
| `escrituras[]` | Uma entrada por ato, da mais recente para a mais antiga |

### Escritura

| Campo | Descrição |
| --- | --- |
| `tipo` / `tipo_descricao` | `Inventario` (Inventário), `InventarioComMenorOuIncapaz`, `Partilha`, `Sobrepartilha`, `NomeacaoDeInventariante`, `DivorcioDireto` (Divórcio direto), `Separacao`, `ConversaoDeSeparacaoEmDivorcio`, `Reconciliacao`, `Retificacao`, `RetificacaoAtoNaoNotarial` |
| `data` | Data da lavratura (`AAAA-MM-DD`) |
| `livro`, `folha` e complementos | Localização do ato no cartório, para pedir a certidão |
| `cartorio` | CNS, nome, município, UF, código IBGE, endereço, e-mail e telefones públicos |
| `qualidades_consultado` | Papel do CPF/CNPJ consultado no ato, por exemplo `Herdeiro` ou `Divorciando` |
| `data_casamento`, `regime_bens`, `filhos_maiores`, `filhos_menores` | Preenchidos em divórcios e separações |
| `responsavel`, `valor`, `mne`, `numero_controle`, `complementacao`, `data_contrato`, `data_validade` | Dados complementares do ato, quando o cartório informou |
| `bens_imoveis`, `referentes` | Bens e atos referentes, quando o cartório informou |
| `incluida_na_censec_em` | Quando o cartório enviou o ato à CENSEC |
| `ids_fonte` | Identificadores do ato na CENSEC. Um ato enviado duas vezes pelo cartório aparece uma vez só, com os dois ids |
| `partes` | Todas as partes do ato. `null` quando a CENSEC não devolveu o detalhe naquele momento |

### Parte

| Campo | Descrição |
| --- | --- |
| `nome`, `cpf_cnpj` | Identificação da parte |
| `qualidade` | Papel no ato: `Falecido`, `Herdeiro`, `Viuvo`, `Inventariante`, `Divorciando`, `Separando`, `Advogado`, `Cedente`, `Anuente` etc. |
| `data_nascimento`, `sexo`, `estrangeiro`, `naturalidade_uf`, `residencia` | Dados pessoais registrados no ato |
| `conjuge_tipo` | `Conjuge1` ou `Conjuge2` em divórcios e separações |
| `documentos` | RG, OAB, passaporte e outros. O CPF/CNPJ fica em `cpf_cnpj` |

## Menores de idade (LGPD)

Herdeiros menores de idade aparecem com nome e CPF mascarados, sem data de nascimento, residência ou documentos, e com `mascarado_motivo: "menor_de_idade"`. A idade é calculada no momento de cada consulta. Quando a CENSEC não informa a data de nascimento, o nome é mantido e os documentos extras (RG etc.) são omitidos, exceto a OAB de advogados.

## Consulta assíncrona

A CENSEC protege a consulta com captcha, então cada busca leva de **10 a 50 segundos**. Por isso a consulta é **assíncrona**: a resposta chega na hora com o endereço do resultado.

```bash
curl "https://221b-api.sherlocker.com.br/api/v1/escrituras/cpf/12345678901?token=SEU_TOKEN"
# 202 { "jobId": "3f2c…", "status": "processing", "statusUrl": "/api/v1/escrituras/jobs/3f2c…" }

curl "https://221b-api.sherlocker.com.br/api/v1/escrituras/jobs/3f2c…?token=SEU_TOKEN"
# { "status": "completed", "result": { "total": 1, "escrituras": [ … ] } }
```

Consulte `statusUrl` a cada 5 a 10 segundos até `status` ser `completed` (a resposta descrita acima vem em `result`) ou `failed` (o motivo vem em `error`). A consulta do resultado é gratuita e fica disponível por 24 horas. O mesmo documento consultado de novo dentro de 24 horas fica pronto quase na hora.

Se a CENSEC falhar, a consulta tenta de novo sozinha até três vezes. Os tokens são estornados quando não há escritura ou quando a consulta termina com falha.

## Erros

| Onde | Status | Quando |
| --- | --- | --- |
| Consulta por CPF/CNPJ | 400 | CPF ou CNPJ inválido. Nada é enfileirado nem cobrado |
| Resultado | `failed` | CENSEC fora do ar, captcha não resolvido ou consulta recusada pela CENSEC, depois das novas tentativas. Tokens estornados |
