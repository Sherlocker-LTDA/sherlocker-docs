# MCP Server

O Sherlocker disponibiliza um servidor [MCP (Model Context Protocol)](https://modelcontextprotocol.io/) que permite que agentes de IA como **Claude**, **Cursor**, **Windsurf** e outros clientes compatíveis consultem dados investigativos diretamente.

## Endpoint remoto

O servidor MCP do Sherlocker esta disponivel na nuvem — nao precisa instalar nada:

```
https://mcp.sherlocker.com.br/mcp?token=SEU_TOKEN
```

Basta conectar seu cliente MCP a essa URL passando seu token de acesso.

## Conectando no Claude Desktop

<Steps>
  <Step title="Abrir configuracoes">
    No Claude Desktop, va em **Settings** → **Developer** → **Edit Config** (ou edite o arquivo `claude_desktop_config.json` diretamente).
  </Step>
  <Step title="Adicionar o servidor">
    Adicione a seguinte configuracao no bloco `mcpServers`:

    ```json
    {
      "mcpServers": {
        "sherlocker": {
          "type": "url",
          "url": "https://mcp.sherlocker.com.br/mcp?token=SEU_TOKEN"
        }
      }
    }
    ```

    Substitua `SEU_TOKEN` pelo seu token de acesso.
  </Step>
  <Step title="Reiniciar o Claude">
    Feche e reabra o Claude Desktop. O Sherlocker aparecera como servidor MCP conectado.
  </Step>
  <Step title="Testar">
    Envie uma mensagem como:

    > "Investigue o CPF 12345678900 e me mostre telefones e empresas"

    O Claude usara automaticamente as tools do Sherlocker para buscar os dados.
  </Step>
</Steps>

## Conectando no Claude Code

No terminal, adicione o servidor com o comando:

```bash
claude mcp add sherlocker --transport http "https://mcp.sherlocker.com.br/mcp?token=SEU_TOKEN"
```

Pronto — o Claude Code ja podera usar as tools do Sherlocker nas suas conversas.

## Conectando no Cursor

<Steps>
  <Step title="Abrir configuracoes MCP">
    Va em **Cursor Settings** → **MCP** → **Add new MCP server**.
  </Step>
  <Step title="Configurar">
    - **Name:** `sherlocker`
    - **Type:** `http`
    - **URL:** `https://mcp.sherlocker.com.br/mcp?token=SEU_TOKEN`
  </Step>
  <Step title="Salvar e testar">
    Salve e o Cursor detectara as tools automaticamente. Voce pode pedir ao agente para investigar CPFs e CNPJs diretamente no chat.
  </Step>
</Steps>

## Exemplos de uso

Depois de conectar, basta pedir ao agente em linguagem natural:

- *"Investigue o CPF 12345678900 — quero saber nome, telefones e se tem empresas"*
- *"Faca uma due diligence completa do CNPJ 12345678000100"*
- *"Descubra quem e o dono da placa ABC1D23"*
- *"Busque empresas vinculadas ao email contato@empresa.com"*
- *"Faca um background check completo dessa pessoa: CPF 12345678900"*

O agente selecionara automaticamente as tools mais relevantes para cada solicitacao.

## Acompanhar Dossiês

Para quem gera Dossiês pela [API de Dossiê](/plataforma/dossie), o MCP traz duas tools de
acompanhamento. Elas usam a mesma chave e exigem acesso a Dossiês na conta.

| Tool | Parâmetros | O que retorna |
| --- | --- | --- |
| `dossie_status` | `id` (UUID do Dossiê) | Estado, fase (`queued`, `waiting_slot`, `generating`, `finished`), posição na fila, últimos marcos da geração e previsão de conclusão. Quando terminou, também resultado e artefatos |
| `dossies_fila` | nenhum | Todos os Dossiês da conta que ainda não terminaram, do mais antigo ao mais novo, com fase, posição, último marco e previsão de cada um |

Exemplos de pedido ao agente:

- *"Como está o dossiê 55555555-5555-4555-8555-555555555555? Quando fica pronto?"*
- *"Quantos dossiês ainda estão na fila e qual termina primeiro?"*

A espera na fila não conta no tempo limite de geração.

<Tip>
  As tools disponiveis sao listadas automaticamente pelo servidor MCP quando o cliente conecta. Nao e necessario configurar nada alem da URL e do token.
</Tip>
