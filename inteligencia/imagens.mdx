<Note>**Em breve.** Contrato proposto; exemplos e valores fictícios.</Note>

Reúne fotos prováveis a partir dos dados disponíveis da pessoa, ordenadas e com suas origens e presença de rosto. Ajuda a identificação visual em um cadastro ou dossiê.

## Entrada

```json
{
  "cpf": "00000000000",
  "nome": "Pessoa Exemplo",
  "emails": ["pessoa@example.org"],
  "telefones": ["5511999990000"],
  "perfis": [{"url": "https://example.org/perfil/pessoa"}]
}
```

## Saída

```json
{
  "imagens": [
    {
      "url": "https://example.org/foto-1.png",
      "tem_rosto": true,
      "quantidade_rostos": 1,
      "origens": [
        {"fonte": "Perfil Exemplo", "url": "https://example.org/perfil/pessoa", "identificador": "pessoa@example.org"},
        {"fonte": "Fonte de Contato Exemplo", "identificador": "5511999990000"}
      ]
    },
    {
      "url": "https://example.org/foto-2.png",
      "tem_rosto": true,
      "quantidade_rostos": 1,
      "origens": [{"fonte": "Outro Perfil Exemplo", "url": "https://example.org/profissional/pessoa"}]
    }
  ]
}
```

## Uso

Mostre as imagens com suas origens. Uma foto encontrada em duas fontes aparece uma vez; sem imagem, a lista fica vazia. Presença de rosto ajuda a apresentação visual, sem confirmar a identidade da pessoa.
