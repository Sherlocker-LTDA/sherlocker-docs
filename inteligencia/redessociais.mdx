Localiza perfis prováveis na web a partir de nome, documento e contatos, trazendo links e sinais que sustentam a associação com a pessoa ou empresa pesquisada.

## Entrada

```json
{"nome": "Pessoa Exemplo", "cpf": "00000000000", "emails": ["pessoa@example.org"], "telefones": ["5511999990000"]}
```

## Saída

```json
{
  "perfis": [
    {
      "id": "perfil_1",
      "plataforma": "Rede Exemplo",
      "nome": "Pessoa Exemplo",
      "url": "https://example.org/perfil/pessoa",
      "correspondencia": "provavel",
      "confianca": "moderada",
      "motivos": ["Nome compatível com a entrada.", "Contato reconhecido pela fonte do exemplo."],
      "origens": [{"fonte": "Pesquisa Web Exemplo", "url": "https://example.org/fonte/perfil", "consultado_em": "2026-10-13T12:00:00Z"}]
    },
    {
      "id": "perfil_2",
      "plataforma": "Rede Profissional Exemplo",
      "nome": "Pessoa Exemplo",
      "url": "https://example.org/profissional/pessoa",
      "correspondencia": "provavel",
      "confianca": "baixa",
      "motivos": ["Nome compatível; contato ainda não corroborado."],
      "origens": [{"fonte": "Pesquisa Web Exemplo", "url": "https://example.org/fonte/profissional", "consultado_em": "2026-10-13T12:00:00Z"}]
    }

}
```

## Uso

Apresente os perfis como uma lista de links com confiança, origem e motivos. Os sinais ajudam a revisar a associação; nome igual, sozinho, não confirma identidade.
