Todas as requisições à API do Sherlocker requerem autenticação via Bearer Token no header `Authorization`.

## Utilizando o token

Inclua o header em todas as requisições:

```bash
curl -H "Authorization: Bearer SEU_TOKEN" \
  https://221b-api.sherlocker.com.br/api/v1/empresas/cnpj/12345678000100
```

## Erros de autenticação

O acesso aos produtos depende das flags atuais da conta/workspace, além da
autenticação válida e do vínculo com o workspace. Não depende de escopos ou de
permissões de produto gravadas na chave. Veja [Autenticação da Plataforma](/plataforma/autenticacao).

| Status | Descrição |
|--------|-----------|
| `401`  | Token ausente ou inválido |
| `403`  | Acesso não autorizado pelo vínculo ou pela habilitação atual da conta/workspace |

<Warning>
  Nunca exponha seu token em repositórios públicos ou código client-side.
</Warning>
